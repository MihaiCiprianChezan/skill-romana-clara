## 2. Attested pairs — calofilie semidoctă [S]

Source: Stratan, "Câteva considerații privind calofilia semidoctă în româna actuală",
UPS "Ion Creangă", Chișinău, 2025. These are words Romanian speakers reach for to
sound educated, at a direct cost in clarity.

**Tier [S], not [N].** The pairs are attested in a published linguistics paper, which
makes them stronger than bare house style. A paper is not a statute, DOOM, or an official
guide, so it does not meet the [N] definition in SKILL.md. Name the source when you use
a pair; do not call it a rule.

| Înainte | După |
|---|---|
| a staționa | a sta |
| a debuta | a începe |
| a demara | a începe |
| a finaliza | a termina |
| calmitate | calmul |
| a lectura | a citi |
| a consuma | a mânca / a bea |
| a concluziona | a trage concluzii |
| a (se) focusa pe | a se concentra pe / a se centra pe |

`a demara → a începe` is attested by two independent sources (this one and the EU guide).
It is the single most defensible pair in the whole reference.

## 4. House style — Latinate verbs and nouns [S]

The plainer member of each pair is usually the more frequent one, and Romanian readers
rate frequent words as easier (RALS, r ≈ −0.5). But the effect is weaker in Romanian
than in English, so use judgment: if the Latinate word is the established term in the
field, Rule 1.4 keeps it.

| Înainte | După |
|---|---|
| a implementa | a aplica / a pune în practică |
| a efectua | a face |
| a realiza | a face |
| a solicita | a cere |
| a deține | a avea |
| a dispune de | a avea |
| a utiliza | a folosi |
| a valorifica | a folosi |
| a facilita | a ajuta / a face posibil |
| a viza | a privi / a se referi la |
| a se prevala de | a folosi |
| a menționa | a spune / a scrie |
| a comunica | a spune / a trimite |
| a transmite | a trimite |
| modalitate | mod |
| problematică | problemă |
| oportunitate | ocazie |
| necesitate | nevoie |
| finalitate | scop |
| demers | acțiune / pas |
| tematică | temă / subiect |
| optică | punct de vedere |
| impact | efect |
| a genera | a produce / a crea |

**Do not apply these mechanically in juridic register.** `a deține`, `a dispune de`, and
`a solicita` carry distinct legal senses that `a avea` and `a cere` do not.

### 7b. NOT pleonasms — never auto-correct these [F]

Each of these circulates on Romanian pleonasm lists. Each one carries a real distinction.
Stripping the "redundant" word is exactly the qualifier-dropping that `verificare.md` F4
forbids.

| Circulating "fix" | Why it is wrong |
|---|---|
| `întârzierea și amânarea` → `întârzierea` | Not synonyms. *Întârziere* is unintended lateness; *amânare* is a deliberate postponement. In a procedure or a contract these are different events with different consequences. |
| `verdict final` → `verdict` | In any system with appeals, `final` distinguishes a definitive ruling from an appealable one. Dropping it changes the legal effect. |
| `sumă de bani` → `sumă` | In a contract with computed amounts, bare `suma` is ambiguous with an arithmetic total. |

If you think one of these is genuinely redundant in the text in front of you, flag it for
the author. Do not decide it yourself.

## 8. Extended slop list [S]

Romanian AI-generated and consultant prose overuses these. They carry no fact.
**Delete rather than replace** — if deletion loses information, it was not slop.

**Frames to delete whole:**
`merită menționat faptul că` · `este important de reținut că` · `trebuie subliniat că` ·
`nu în ultimul rând` · `este de menționat că` · `se cuvine să precizăm` ·
`în acest context` (usually) · `din punct de vedere tehnic` (usually) ·
`la nivel general` · `pe de o parte… pe de altă parte` (when there is no real contrast)

**Empty intensifiers to delete:**
`pur și simplu` · `ușor` (as praise — never in `ușor inflamabil`) · `rapid și eficient` · `fără efort` · `în mod fluid` ·
`în mod eficient` · `cu ușurință` · `perfect` · `complet` (when it adds nothing)

**Empty praise — delete, or give the measurable property:**
`robust` · `puternic` · `cuprinzător` · `performant` · `de ultimă generație` ·
`extrem de rapid` · `de înaltă calitate` · `inovator` · `revoluționar` ·
`scalabil` (unless you state to what) · `soluție de tip X`

**Rewrites rather than deletions:**

| Înainte | După |
|---|---|
| este conceput pentru a | (say what it does) |
| are ca scop | (say what it does) |
| permite utilizatorului să | puteți |
| oferă posibilitatea de a | puteți |
| funcționalitate | funcție |
| a aborda problema | a corecta eroarea |
| gestionează elegant erorile | (say how: `reîncearcă de trei ori, apoi se oprește`) |
| din start / by default | implicit |
| în spate / sub capotă | intern |
| a eficientiza | a face mai simplu / mai rapid |
| și/sau | `X, Y sau ambele` — **never "pick one"**, which always changes the meaning. No comma before `sau` (IER 2008, §3.1.2). Exception: in a translation of an EU act, keep `și/sau` where the source has *and/or* (domenii.md §4) |
| etc. | `și altele` — preserves the open list. Name the items **only** when the source says what they are; otherwise you are inventing them (F5). Deleting `etc.` outright loses information. |
| ș.a.m.d. | `și așa mai departe`, or `și altele` — same caution as `etc.` |

## 9. Consistency sets

Pick one member of each set and use it everywhere — headings, body, tables, buttons,
error messages. Legea 24/2000 Art. 37 alin. (1) makes this binding in normative text.

- `configurare` / `configurație` / `setări` / `parametri` / `opțiuni`
- `a șterge` / `a elimina` / `a suprima` / `a înlătura` / `a radia`
- `eroare` / `problemă` / `defecțiune` / `incident` / `disfuncționalitate`
- `verificați` / `asigurați-vă că` / `confirmați` / `validați` / `controlați`
- `a rula` / `a executa` / `a lansa` / `a porni`
- `a afișa` / `a arăta` / `a prezenta` / `a reda`
- `utilizator` / `client` / `beneficiar` / `solicitant` / `petent`
- `cerere` / `solicitare` / `petiție` / `sesizare`
- `document` / `act` / `înscris` / `documentație`
- `termen` / `termen limită` / `scadență` / `dată limită`

Record the choice at the top of the document or in a glossary, so the next writer
inherits it. Rule 1.6 requires this when the term could be read more than one way.

## 10. Pairs deliberately NOT included

These circulate as "rules" but I could find no Romanian normative or stylistic source
behind them, and several are wrong often enough to do damage:

- `a fi` → anything. The verb is fine.
- Blanket `neologism` → `cuvânt vechi`. Legea 24/2000 Art. 36 alin. (2) applies only
  when a *widely known* synonym exists, and Art. 36 alin. (3) explicitly protects
  established specialist terms.
- Blanket removal of the passive. *Mic ghid* Rec. 7 says the opposite:
  `Nu este nevoie să evitați diateza pasivă cu orice preț.`
- "Accepted cacophonies" lists. No normative status. Do not enforce cacophony at all.
- `ca și` in genuine comparison. Only the anti-cacophony insertion is criticized.
